## Incomplete source passages

Private prompt3 and shared prompt4 conservatively exclude any source passage containing ellipsis markers (`...`, `…` or bracketed forms) from model input and citation eligibility. Stable IDs of surviving passages are preserved. This may also omit a complete sentence carrying an ellipsis; it is not a general detector of incomplete prose. Original source title/body remain unchanged in storage and inspection. Excluded fragments are counted separately from omitted sources and explained in the result.

The source projection also excludes an ellipsized title or publisher field, preventing the removed text from re-entering through metadata. User-written reasoning is preserved unchanged. If no usable evidence remains (no usable news for the shared news briefing), the request stops before cost reservation. Historical saved results remain historical; a corrected prompt creates a different request identity rather than overwriting old output.
