### Reviewed annual amendments

The former AMD-specific exception is superseded by **`sec-amendment-resolution-1`**, a read-time resolver shared by the competitor, reported-performance and financial-history views. No issuer/accession allowlist remains. It keeps usable amended structured figures; an absent figure can use the nearest compatible earlier filing only when **every intervening amendment** supports it. The complete same-period chain is bounded to eight filings and must start with an original annual or quarterly report.

Support comes from the retained original amendment: either a narrowly recognized, unconditional Explanatory Note statement leaving the financial statements unchanged, or simple visible two-period USD tables repeating the exact current/prior whole-company totals. Table evidence supports only the totals it proves (revenue/growth, operating income, and margin when both are established). Document identity, issuer, form, period, acceptance time, canonical URL, raw hash and text hash must match. Qualified/restatement language cannot establish a blanket unchanged statement; conflicting amended facts, unsupported dates/units/tables, missing chain members and unavailable document permission remain unknown. This is deliberately bounded extraction, not general understanding of every SEC amendment.

The shared evidence modal links both filings and summarizes the amendment status with readable amounts; the exact decimals and supporting rows remain in the retained source data. No screenshot value or quarterly substitution is used.

Read-time output has its own `projection_id`, `projection_method`, retained payload ID and `based_on_snapshot_id`; its `snapshot_id` is null.
