### One peer action and visible data status — 12 October 2026

Type a ticker or company name in **Peers**, then select a match or press Enter. An exact ticker or unique match can also go directly through **Save & compare**. Selected peers appear above the charts with a remove control and a data status. The one action saves the owner-private group, applies it to the charts, and sequentially checks missing financial data. Existing comparison reasons are retained without the repetitive reason editor. Up to eight different peers are supported. Same-issuer share classes, duplicate symbols and unknown identities remain rejected. Clearing saved peers restores the default group when one exists. Draft changes are not saved automatically and survive switching tabs within the same company.

Each peer distinguishes **Fetching**, **Not collected**, **Fetch failed**, **No annual report**, **Source unavailable**, usable data and a different fiscal year-end. Read-only `filing_status` uses permitted saved reports, current filing leases and queued/running filing steps; no unsupported period or zero is invented. Existing in-flight collection is polled without another fetch. A failed save keeps the draft and starts no collection. A successful save remains applied if a subsequent source check fails; other pending peers can still finish and update the charts. Source results remain Fetching until the updated projection has loaded. Leaving the comparison stops later source dispatches; an already dispatched request keeps its normal outcome. Completed usable annual data is reused, with original amendments collected only when the existing resolver needs them.

### Reviewed annual amendments

The former AMD-specific exception is superseded by **`sec-amendment-resolution-2`**, a read-time resolver shared by the competitor, reported-performance and financial-history views. No issuer/accession allowlist remains. It keeps usable amended structured figures; an absent figure can use the nearest compatible earlier filing only when **every intervening amendment** supports it. The complete same-period chain is bounded to eight filings and must start with an original annual or quarterly report.

Support comes from the retained original amendment: a narrowly recognized, unconditional Explanatory Note statement leaving the financial statements unchanged; an explicit sole-purpose MD&A correction with unchanged other items and Item8 outside the amendment scope; or simple visible two-period USD tables repeating the exact current/prior whole-company totals. The MD&A rule also requires Item7 content (optionally an Item15 index), no other amended item, and no restatement/financial-statement change in the note. Table evidence supports only the totals it proves (revenue/growth, operating income, and margin when both are established). Document identity, issuer, form, period, acceptance time, canonical URL, raw hash and text hash must match. Qualified/restatement language cannot establish a blanket unchanged statement; conflicting amended facts, unsupported dates/units/tables, missing chain members and unavailable document permission remain unknown. This is deliberately bounded extraction, not general understanding of every SEC amendment.

AMD FY2025 now resolves through its explicit MD&A-only amendment scope, with the repeated tables as separately supported evidence, without special code: original `0000002488-26-000018` supplies USD34.639bn/25.785bn and growth34.33779329067287182470428540%; amendment `0000002488-26-000021` repeats those totals. The shared evidence modal links both filings and summarizes the amendment status with readable amounts; the exact decimals and supporting rows remain in the retained source data. No screenshot value or quarterly substitution is used.

Read-time output has its own `projection_id`, `projection_method`, retained payload ID and `based_on_snapshot_id`; its `snapshot_id` is null. The unmodified `recorded_basis` remains available for persisted valuation cases. Model research, historical exports/monitoring and saved performance snapshots retain their existing immutable basis. Frontend peer validation recognizes the projection separately. Financial history/TTM uses the same resolver with the existing annual/YTD arithmetic, exact input accessions and source URLs; derived figures cannot mix incompatible amended vintages. Retained evidence includes every supporting table; the UI uses a concise amendment explanation and original-report links. A document-basis identity invalidates cached financial-story views when evidence or permission changes.

**Save & compare** uses the existing structured refresh for missing financial data. If the saved result needs amendment text, it invokes the existing original-filing collector. That collector also retains up to seven preceding amendments in the current same-period chain, reusing already saved older documents; auxiliary documents do not replace the normal business-brief selection. Existing source entitlement, SEC pacing/archive denials, 15-minute company cooldown, three-minute lease and late-result fencing remain. Navigation stops later dispatches. Merely viewing the chart makes no source or AI request. Cooldown and collection failures are shown rather than automatically retried.
