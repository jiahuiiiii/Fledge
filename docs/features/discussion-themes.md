Each theme shows what its cited sources say, an optional differing view about the same issue, and one unresolved question. The source count is a count of selected texts, never independent confirmations. A single author's two opinions can supply both views. The model receives eligible complete source passages and source metadata, not sentiment scores, private reasoning, parent conversations or linked full articles. This inherits relevance-classifier omissions and does not establish exhaustive coverage. Ambiguous replies may provide no useful theme.

## Additional evidence check

New readings now have two explicit, metered steps: synthesis (`thesis-discussion-themes-6`) and a bounded second pass (`discussion-theme-evidence-check-1`). Both use the existing pinned model, original ledger and 6,000-token limit. The second pass reviews claims against their own quotations, full-source contradictions, same-issue differing views, headings and sample limitations. It returns a complete set of accept/withhold decisions; code can remove a whole theme or gap but cannot rewrite the generated prose. A malformed, incomplete or timed-out check publishes no new reading. The original synthesis remains cached, so an explicit continuation does not need another synthesis charge. Neither stage automatically retries.

Published JSON retains the checking policy, checking call identity and withheld counts. The original candidate and review reasons remain in their immutable metered-call records. The UI/export disclose withheld themes and state that this AI check can still miss errors. It is the same model in a separate request, not independent fact-checking. Source withdrawal before the second step prevents its dispatch; withdrawal during that step withholds the completed reading through the existing source boundary. Earlier readings remain unchanged and carry the earlier-method warning.

The actual evaluation caught NVIDIA's false opposition and an unsupported Microsoft gap. It missed a Microsoft claim that needed an unselected antecedent, so the Microsoft candidate was not published. Amazon's check timed out and the authored positive control was not dispatched. Only the manually reviewed NVIDIA result was added to product research. See the phase review for the complete outcome, timeout and remaining limitations.


## Saved conversation context — phase 37

New readings use `thesis-discussion-themes-7`, `theme-source-title-parent-2` and `discussion-theme-evidence-check-2`. Both existing model steps now receive any verified parent already pinned to a source in the selected sentiment analysis. They never fetch a parent, attach a later parent to an older sample, or use unselected raw parent text. The preceding comment-only descriptions are historical; old results retain their original inputs and method notices.

Each context-bearing claim has its own child-body evidence and one or two own-parent quotations. A parent's statement or headline cannot be attributed to the child, counted as another source, or used as independent corroboration. Unresolved ambiguity may lead to no finding. The second step checks selected child and parent evidence together; other eligible passages can expose a contradiction or omission, but cannot repair a claim missing its own support.

Expand **Inspect supporting passages → Parent context used for this finding** for separate quotations, publication/check dates, saved parent text and the original link. The saved full text is for human inspection; the models receive only the explicitly selected eligible passages. Downloads retain selected parent evidence and the original link. Counts remain counts of original selected texts. A newer parent check does not alter any saved interpretation.

Old samples without context remain context-free. Withdrawn parents withhold dependent readings; a withdrawal between the two model steps prevents the second dispatch. Budget reservations, cache reuse, manual-only generation, no automatic paid retries and default-off watches are unchanged. This is software integration, not proof of improved model accuracy.
