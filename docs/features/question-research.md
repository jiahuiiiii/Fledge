# Question-focused research

**Phase 43 status (3 October 2026):** A separate evidence checker was evaluated on sixteen bounded requests, with unchanged candidate findings and positive controls. It remains disconnected from app publication: higher effort improved selected-case matching but still missed errors and raised false-rejection concerns. Existing source/answer/alert behavior is unchanged. See [the evaluation and five-perspective review](../reviews/2026-10-03/finding-checker-phase-review.md). This is not a validated fact-checking layer or completion of the implementation plan.


Current method `thesis-research-answer-5` selects evidence before prose and rejects reported findings citing any social material, including mixed news/social citation lists. Four actual-provider checks tested three retained company packets and an authored control. The Amazon answer met selected criteria; Microsoft still depends partly on unselected context, NVIDIA was rejected for missing parent citations, and two answers omit an explicit changed opinion. These failures remain open. Old answers are not rewritten. [Results and next work](../reviews/2026-10-03/finding-grounding-phase-review.md).

Open a real-company workspace and use the single **Research question** card. Select a saved question, **Add question** to save another, or **Edit question** to replace the selector with a draft field. **Cancel edit** restores the saved selection. Choose **Answer this question** in the same card to submit; selecting, adding and editing never submit automatically. Saved answers remain separately labelled by their original question. Follow-up actions open the draft field and retain the chosen answer as their parent; selecting another saved question clears that parent. No saved idea is required. The explicit action uses the original private OpenAI allowance; reading history, inspecting sources and downloading make no paid or source requests. A no-source answer is saved as insufficient without a model call.

The source sample contains up to eight news snippets from the last seven days, optionally three retrieved Reddit posts/Hacker News comments, and the current available annual/direct-quarter financial tables. News must explicitly mention the target company. Selection uses question-term overlap, then publication time, with byte limits; it is not an exhaustive search. The prior question helps interpret a follow-up, but previous AI answers are never treated as facts. Source refresh remains separate.

Answers distinguish supported-within-sample, partial and insufficient coverage. Every answer claim/evidence point has validated original passage IDs and code-resolved quotations. Partial/insufficient outputs name gaps. All generated evidence prose is displayed as an AI reading. Its news/social/filing category comes from the cited stored sources, not the model's unreliable point-type labels. Original source passages and code-formatted financial values remain inspectable. Raw model labels are preserved for audit, not presented as verified facts. An exact quotation does not prove that the generated conclusion follows. Filing citations quote **code-formatted figures**, retaining annual, direct-quarter, YTD and balance dates; they are not verbatim filing prose. Missing values stay missing and the model does not calculate new ratios or forecasts.

Private immutable history retains the question, optional parent, complete selected source packet, cutoff, model request and result. Identical same-day requests for the same owner/evidence reuse the response. Follow-up context, changed selected evidence or a new UTC date create a distinct request; a provider failure never triggers an automatic paid retry. Old answers retain their original question even if the editor changes. Earlier-method answers carry a visible warning about retained interpretation/attribution issues; their stored results are not rewritten. A saved answer is not refreshed by opening it. History pages contain twenty records and can retrieve older pages.

**Use this question in idea draft** opens the existing editor with the selected question; saving/monitoring still require their existing explicit actions. No question action silently creates an investment idea, enables a watch or marks research resolved. A local HTML download contains the private question, result, source sample and cutoff. Current source access is rechecked for reads/history/exports; losing any consumed source withholds the answer, including when loss occurs during generation.

Migration 017 uses restricted owner rows, immutable records and same-owner model-call and same-company parent foreign keys. The existing single API, PostgreSQL, ledger and model gateway are reused. Deus's dated citations and evidence-sufficiency design inform the workflow; no generic chat framework, autonomous search agent, new provider or database is added. The supported catalogue is MSFT/AAPL/GOOGL/NVDA/AMZN/META.

See the [phase review](../reviews/2026-10-02/question-research-phase-review.md) for verification, actual-source results and unresolved limits.


## Saved reply context — phase 38

New answers use `thesis-research-answer-4`. They retain each social source's platform, exclude the generic HN title from evidence, and can attach recently verified saved parents to the exact selected comments. Selection still ranks original news/posts first; a parent cannot add a source, improve its ranking or invent a company match. No saved idea or prior sentiment classification is required. Parents are read from the existing original-conversation store without network acquisition, using the same 24-hour/count/byte limits as sentiment. New answers do not silently refresh old ones.

Each direct answer or evidence point citing a context-bearing reply must include its own child-body quotation plus one or two own-parent passages. Parent references use the child's source identity and the parent's local passage IDs, in a separate field. They cannot stand alone, attach to an unrelated/news/filing source, or satisfy another evidence point's references. Model instructions preserve author/message boundaries, unresolved pronouns, current/past stance and uncertainty. Exact citations do not establish semantic correctness.

Answer evidence exposes **Parent context used for this finding**. The source dialog shows all eligible **Saved parent passages supplied to this answer**, distinguishing model inputs from selected support. Social sample counts separate Reddit and HN; parents add no sources. Downloads preserve selected parent quotations, dates and the original link. Changed or failed later parent checks do not alter historical answers. Identical parent rechecks reuse same-day cached answers; changed semantic context or expiry changes the next request.

Opting out of social sources also excludes parent context. Fresh requests omit unavailable/stale/withdrawn parents; an existing answer that consumed a withdrawn parent is withheld through reads/history/export, including withdrawal during generation. Question history, private ownership, follow-up-question-only context, source limits, cumulative accounting and no automatic paid retry remain unchanged. No watch, saved idea or research-resolution action is created.

[Five-perspective review](../reviews/2026-10-03/question-context-phase-review.md) separates software and retained-input verification from actual model quality, which remains untested for this new prompt while the earlier charge is unresolved.
