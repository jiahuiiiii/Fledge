# Portable research record

2 October 2026. `Download research record` in My idea and History exports one explicitly selected saved definition, numerical assessment or AI comparison as an offline HTML file. It needs no server after download and can be printed by the browser. Downloading never refreshes a supplier or invokes a model.

A definition export contains the saved question, reasoning and conditions, without implying an evaluation. An assessment export contains its original cutoff, assessment time, numerical outcomes, reporting period, source references and review acknowledgement as of download. An AI-comparison export includes that exact interpretation and its quoted evidence; a linked numerical assessment is included only if it belongs to the same revision. Exporting an assessment does not silently pick an AI interpretation. Later revisions, snapshots and corrections cannot replace the selected history.

The server derives the account from the existing local session and verifies version ownership under the restricted application role. It reads through the current source whitelist. An unavailable historical source suppresses dependent numerical result content or the whole affected interpretation point. Raw provider requests, keys, unrelated ideas and other users' records are excluded. News sources are represented by references and the comparison's quoted excerpts; recorded and SEC calculation source text is available inside disclosure sections. This is a local private export, not an approval to redistribute all provider content.

All content is HTML-escaped, publisher links accept only HTTP(S), no script or remote asset is included, and an embedded content policy prevents active content. The filename uses catalogue symbol/revision and record ID, not private reasoning. Downloads show a private-notes notice and do not imply an AI interpretation is verified because its quote matches.

Verification: seven backend cases exercise historical numeric values after edits/archive, definition-only behavior, cross-owner/mismatched-record rejection, changed source access, HTML/link injection, local-session/attachment/no-store behavior and unrelated private-content exclusion. The extended idea browser journey downloads a selected old comparison, opens it without network resources, checks desktop/phone layout, and preserves the selection after an injected download failure. These use disposable authored fixtures. The installed actual Google download is recorded separately in the overnight report.
