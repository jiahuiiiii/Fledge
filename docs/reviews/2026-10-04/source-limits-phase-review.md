It drops complete comparison-only reports first, keeping the longest ranked prefix that fits. If originals alone exceed the ceiling, it removes the last-selected original from the most populated channel/platform, using total size for ties. It never shortens a selected passage or detaches its supplied parent merely to fit. Existing fragment-exclusion and source-sampling rules still apply.

A request that already fits stays unchanged. No valid complete-source request means an empty preview and a descriptive pre-dispatch error, with no reservation.
