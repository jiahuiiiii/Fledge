## Retained failures

The NVIDIA run calls an accounting opinion teaser a reported development while classifying the fuller related criticism as opinion. A separate adds-detail link joins identical supplied body text under Rise/Loom headlines; this can create an update if the older report was seen. Body equality alone is not a safe general suppression rule because headlines can contain a real correction. No new suppression heuristic was installed.

One NVIDIA question answer combines an opening ray-tracing sentence whose surrounding text concerns an AMD card with a specific NVIDIA Linux penalty. Missing antecedent context can mislead despite exact quotations. Another answer's NVIDIA 5070 detail is in the supplied text but outside its two selected quotation passages. It is incomplete selected-citation coverage, not an invented source fact. These failures prevent a general quality-pass claim; frozen labels were not changed to improve scores.
