# Phase 2 provider and evidence review

Three AI reviewers covered architecture, product/UX, and evidence/business. No reviewer accessed keys or made provider requests.

Architecture required an anchored original installation, a closed text-only request contract, immutable settled charges and a one-use dispatch record. All were implemented and tested before the reviewer cleared a bounded live smoke call. Ambiguous requests retain reservations and block new spending. Source selection and cost accounting do not complete the product.

Evidence review accepted the authored-corpus smoke boundary and required intact paragraphs rather than fragile sentence splitting, visible omitted-source context, and an empty-source workspace that does not fail solely because optional model selection is unavailable. These were implemented with focused regression cases. Exact quotations establish what the source said, not that it is true or balanced.

Product/UX review required status refresh after a failed AI request, a distinct expectations answer, and no impossible selection action when sources are empty. These were implemented and exercised in the browser. The ordinary sourced baseline remains usable when models are disabled or paused.

The root agent ran the offline suite/browser and three separate metered live checks. All required authored source cases passed; repeated requests reused responses. Cost was US$0.00221475, with no outstanding reservation. A timezone difference discovered during final app integration was normalized and regression-tested so equivalent timestamps share one request identity.
