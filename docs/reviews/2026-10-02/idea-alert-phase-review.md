# Phase 12 — private reasoning relevance and quieter alerts

This is a parent-authored review from five perspectives. It is not five independent consultant opinions, a student study, or a claim of investment accuracy.

## What changed and why

Generic negative sentiment is too broad to explain why someone should revisit a saved idea. The implementation now compares new selected sources with the exact saved reasoning revision. A separate private prompt selects meaningful supports/challenges or specific risks to investigate, while context/unclear/unrelated results stay quiet in History. It can be requested explicitly or selected as the focus of an opt-in local news/social watch. Sentiment direction is not an input to private matching.

## Verification

The full integrated backend suite passed **317 tests** with the actual saved SEC corpus. The final suite includes the new risk category and its owner/source-pinned review/export checks. Five frontend checks and the production build pass. The final dedicated browser journey passed after the 16-item coverage and unread-count changes: explicit watch scope, exact earlier reasoning/source, private inert export, acknowledgement, quiet history, edit/archive persistence and no overflow at 320/390/1440 pixels. The existing private-history browser journey also passed during this phase before the final copy/count changes.

Automated providers are mocked and browser sources are labelled fixtures. Initial test launches were blocked by sandbox shared-memory restrictions before executing checks; the same suites then passed with an isolated local PostgreSQL process. No production test database was used.

Upgrade backups and row comparisons preserve the existing app records, all original model charges/reservations and private configuration. Migration 013 is installed. Main-owner watches remain off. Actual-source live testing and its retained failures are documented in the accompanying real-case review.

## Decision

Keep this bounded implementation for the local pitch. Do not advertise validated detection or treat every model connection as a fact. The live noise findings show why quotation checks alone are insufficient. Next useful work is a broader frozen case set and usable alert triage, followed by the outstanding fundamentals/valuation scope where needed for the pitch. More features cannot substitute for participant validation.
