## Implemented behaviour

The new `answers` relation links exactly one supplied question or reasoning segment. It never invents a stance, rewrites the idea, changes conditions or marks research resolved. Supports/challenges still require an asserted belief; risks remain distinct. Background overlap, missing proof, unsupported opinion and a launch incorrectly treated as paid adoption stay quiet by instruction. Exact quote validation is a code check; semantic support remains a model judgment.

Manual checks use the selected current sample. Opt-in watches keep the existing quiet baseline and seen-content rules; a prompt upgrade does not reprocess old baseline material. No main-account watch was enabled. Old v4/v5 records retain their own outputs and remain accessible. Question-only evidence uses the same immutable saved revision, not a separate watch system.
